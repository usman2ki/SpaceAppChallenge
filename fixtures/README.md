# Fixtures — SYNTHETIC, NOT NASA MEASUREMENTS

Every file in this folder was written by hand or generated by
`ember_atlas.synthetic` for testing. The values imitate the *format* of NASA
FIRMS CSV exports (column names, codes, units) so the parser is exercised,
but they are **not** satellite observations and must never be presented as
such. Files are prefixed `SYNTHETIC_` and are imported with
`--origin synthetic`, which keeps them separate from real data everywhere in
the app.

| File | Purpose |
|---|---|
| `SYNTHETIC_tiny_modis_sp.csv` | 8 MODIS rows: Terra + Aqua, a 3-digit `acq_time` (`130` = 01:30 UTC), one exact duplicate row, one `type=2` static land source, confidence values across all three classes |
| `SYNTHETIC_tiny_viirs_snpp_sp.csv` | 8 VIIRS S-NPP rows near the MODIS rows, with l/n/h confidence codes |
| `SYNTHETIC_malformed_modis.csv` | One valid row followed by one example of each validation failure (bad latitude, ambiguous date, invalid time, unknown platform, confidence out of range, wrong field count, NRT row in a declared standard file, platform/instrument mismatch, negative FRP, null island, invalid day/night flag) and a conflicting re-observation |
